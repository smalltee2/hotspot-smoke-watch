# เกี่ยวกับคู่มือนี้ {.unnumbered}

คู่มือนี้อธิบายระบบพยากรณ์ SEA-HAF แบบครบวงจร ตั้งแต่หลักการไปจนถึงการใช้งาน แบ่งเป็นสามภาค:

| ภาค | บท | เนื้อหา |
|---|---|---|
| ก. วิธีการ (Methodology) | 1–3 | ภาพรวมระบบ ข้อมูลนำเข้า และวิธีการพยากรณ์และปรับแก้ เขียนในรูปแบบบทความวิชาการ |
| ข. การประเมินแบบจำลอง (Model evaluation) | 4 | ผลการตรวจความแม่นยำจาก log การพยากรณ์จริงและข้อมูลย้อนหลัง |
| ค. คู่มือการใช้งานและอ้างอิงทางเทคนิค | 5–8 | การใช้หน้าเว็บทุกส่วน การติดตั้ง ค่าตั้ง โมดูล ไฟล์ผลลัพธ์ การดูแลระบบ และภาคผนวก |

**ข้อตกลง**

- ค่าพารามิเตอร์ทุกตัวในคู่มือคัดลอกจากโค้ดใน branch `main` ณ วันที่ออกฉบับนี้ ถ้าโค้ดเปลี่ยน ให้ถือโค้ดเป็นหลัก
- ตัวเลขผลการประเมินคำนวณจาก log จริง และระบุช่วงวันที่ของข้อมูลกำกับไว้
- คู่มือไม่มีค่า key, token หรือรหัสผ่านใด ๆ มีเพียงชื่อของ secret ที่ระบบต้องใช้

หน้าเว็บหลักอยู่ที่ <https://sea-haf.pages.dev> และสำรองไว้ที่ GitHub Pages ส่วนโค้ดอยู่ที่ <https://github.com/smalltee2/hotspot-smoke-watch>
