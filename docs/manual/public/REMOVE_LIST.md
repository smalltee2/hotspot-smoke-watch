## 2. เก็บไว้ เพราะมีผลต่อสิ่งที่แสดง

- **PM2.5 พยากรณ์ (CAMS เท่านั้น)**
  - CAMS, การตรวจค่าวัด (spike check และ "ค่ารอยืนยัน"), Kalman, regression kriging และ ML v1
  - hindcast expert: เป็นส่วนหนึ่งของ ML v1 และทำงานช่วง 18 ธ.ค. – 30 เม.ย.
  - ค่าเฉลี่ย 24 ชม. แบบ blend
- **ฝน อุณหภูมิ และลม**
  - ฝน ECMWF open data และ rain blend 1–2 ชม.
  - ฝนที่ผ่านมาจาก PARDIG, GSMaP และเรดาร์
  - การปรับแก้อุณหภูมิ 2 ม.: lapse rate และ weather ML ที่ทำงานเมื่อผ่านด่าน
  - ลม 10 ม.
- **คำเตือนและผลิตภัณฑ์**
  - กฎการเตือน สีระดับ เครื่องหมายเตือน และสรุปพยากรณ์
  - การ์ดความแม่นยำ: 100 − NRMSE
- **จุดความร้อน FIRMS** และ trajectory "อากาศมาจากไหน"
- **แชต "ถาม SEA-HAF"** (ส่วนที่ผู้ใช้เห็น) และ IQAir
- **บทประเมินผล:** เก็บเฉพาะแถว CAMS ดิบ → Kalman → ML v1 (published) และ kriging (B.3.4) รวมทั้ง B.7 hindcast (คุณภาพของ CAMS ดิบในฤดูฝุ่น), B.9.1 ช่วงฝุ่นสูง และ B.10 ข้อจำกัด

## 3. ส่วนที่ต้องตัดสินตามสถานะ

**Nowcast 1–6 ชม.** (3.3.8, B.5, 7.3.3)
- ระบบเผยแพร่เมื่อด่านตรวจ 14 วันผ่านเท่านั้น ด่านจะตัดสินครั้งแรกคืน 28 พ.ย. 2569
- ถ้าผ่าน ให้เก็บไว้ ถ้าไม่ผ่าน ให้ตัดเหมือน ML v2

**บทที่ 6–7 (technical reference และ operations)**
- ถ้าคู่มือนี้มีไว้ให้ประชาชนหรือผู้ใช้หน้าเว็บ ให้ตัดทั้งสองบท และเหลือเพียงตารางแหล่งข้อมูลกับหน้าที่ของระบบแบบย่อ
- ถ้าคู่มือยังมีไว้ให้ผู้ดูแลระบบด้วย ให้เก็บสองบทนี้ไว้ แต่ตัดส่วนของ SILAM, v2 และ clim blend ตามข้อ 1
